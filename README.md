# SIF-Precursor-NLP-Engine
An AI/NLP engine that classifies industrial safety reports as SIF-potential (Serious Injury/Fatality) vs non-SIF, tags IOGP Life-Saving Rules, and visualizes SIF density via an interactive dashboard. Built for Oil India's UA/UC observations using DistilBERT + spaCy NER + SHAP explainability.
